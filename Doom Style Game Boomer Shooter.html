Gameplay takes cues from the Doom Bible: rapid forward motion, weapon tiers, ammunition, keys, doors, and combat-first exits.

Includes user-supplied DOOM sprite sheets for personal prototype use. DOOM assets remain the property of their respective rightsholders.

Built with plain HTML, CSS, Canvas, and JavaScript so it can run as a simple website.
